# Scrypted doorbell assets

Audio files used by Scrypted automations to announce a UniFi G6 Entry doorbell on selected Google Cast speakers.

- [Three-ring doorbell chime](./audio/doorbell-3x.mp3): three repeats of the original doorbell sound with short pauses.
- Direct MP3 URL for Scrypted: https://raw.githubusercontent.com/aarondglover/scrypted/main/audio/doorbell-3x.mp3

Original doorbell sound: [SoundMonster public domain doorbell](https://github.com/jonjonsson/SoundMonster/blob/main/Public%20domain/doorbell.mp3).
